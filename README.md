LOGIN / CREATE

Sistema web desenvolvido para demonstrar, de forma prática, os conceitos fundamentais do CRUD, conjunto de operações utilizado para criar, consultar, atualizar e excluir dados em uma aplicação.

Funcionamento

Ao acessar a aplicação, o usuário pode inserir informações e salvá-las localmente. Essa operação representa o Create (Criar), responsável pela criação e pelo armazenamento de novos registros.

Após salvar as informações, o sistema redireciona o usuário para a página de visualização dos dados inseridos. Essa etapa corresponde ao Read (Ler), operação que permite recuperar e consultar os registros previamente armazenados.

Na aba Create, o usuário pode inserir novos dados ou modificar informações existentes, conforme as funcionalidades disponíveis. Quando um registro existente é alterado, a operação realizada corresponde ao Update (Atualizar), responsável por modificar dados previamente armazenados.

Por fim, na página de perfil do usuário, é possível utilizar a opção Delete para excluir os registros armazenados localmente. Essa operação representa o Delete (Excluir), responsável pela remoção dos dados selecionados.

Conceitos demonstrados

A aplicação apresenta as quatro operações fundamentais do CRUD:

- Create (Criar): inserção de novos registros.
- Read (Ler): consulta e visualização dos dados armazenados.
- Update (Atualizar): modificação de registros existentes.
- Delete (Excluir): remoção de registros armazenados.

Dessa forma, o projeto demonstra o funcionamento básico dessas operações em uma aplicação web, utilizando o armazenamento local para persistir os dados no ambiente do usuário.
